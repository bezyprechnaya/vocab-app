Файлы старого приложения. В новой версии не используются: приложение берёт слова
из пакетов `packs/`. Здесь они лежат как исходник ручной работы — 3610 выверенных
русских переводов и 208 фразовых глаголов с примерами.

`tools/import-legacy.py` раскладывает их в `tools/data/wordlist-en.csv`
и `tools/data/overrides-ru.csv`, откуда их берёт сборщик пакетов.
