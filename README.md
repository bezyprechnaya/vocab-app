# Словарь дня — тренажёр английских слов

Ежедневный тренажёр для изучения английской лексики по спискам CEFR. Каждый день приложение выдаёт **10 новых случайных слов** текущего уровня и ведёт их через три этапа:

1. **Сортировка «знаю / не знаю»** — слова, которые вы уже знаете, отмечаются и больше не выдаются, а вместо них добавляются новые, пока не наберётся 10 незнакомых.
2. **Заучивание по карточкам** — флип-карточки «слово → русский перевод», сложные слова можно повторять, пока не запомните.
3. **Финальная проверка** — «Помнишь перевод?» по каждому слову; не вспомненные возвращаются в карточки, и проверка повторяется до чистого прохода.

В конце дня доступен экран **истории**: список прошедших дней с выученными словами и переводами. Уровни осваиваются по порядку: сначала **B1**, затем **B2**, затем **C1** — новый уровень начинается, только когда в предыдущих не осталось неизученных слов.

Дополнительно есть отдельный режим **«Фразовые глаголы»**: 5 случайных глаголов в день со значениями и примерами (английским и русским), собственным прогрессом «выучено из 208» и своей секцией в истории. Режим не заменяет основные слова — оба режима можно проходить в один день независимо.

Весь прогресс хранится **локально в браузере (IndexedDB)**


## Как скачать

- **Архивом**: на странице репозитория нажмите `Code → Download ZIP` и распакуйте архив.
- **Через git**:

  ```bash
  git clone https://github.com/bezyprechnaya/vocab-app.git
  ```

## Как запустить
  

Откройте терминал в папке проекта и запустите один из вариантов:

- если установлен **Python**:

  ```bash
  python3 -m http.server 8000
  ```

  затем откройте в браузере <http://localhost:8000>;

- если установлен **Node.js**:

  ```bash
  npx serve .
  ```

  затем откройте адрес, показанный в терминале.

> На Windows вместо `python3` при необходимости используйте `python -m http.server 8000`.

## Как пользоваться

1. Отметьте слова, которые уже знаете («Знаю это слово»); остальные попадут в набор дня.
2. Выучите слова по карточкам: переверните карточку, чтобы увидеть перевод; кнопка «Повторить ещё» вернёт слово в конец очереди.
3. Пройдите финальную проверку «Помнишь перевод?» — пока не вспомните все слова.
4. На экране «Готово на сегодня!» доступна статистика дня, прогресс по спискам B1, B2 и C1 и кнопка **«Посмотреть историю»** — история выученных слов по предыдущим дням.

Новый набор слов выдаётся каждый день **в полночь**.

## Данные слов

Списки слов встроены прямо в приложение — файлы `words-b1.js` (уровень B1, 842 слова), `words-b2.js` (уровень B2, 1439 слов) и `words-c1.js` (уровень C1, 1329 слов) с русскими переводами. Всего **3610 слов**. Отдельный файл `phrasal-verbs.js` содержит **208 фразовых глаголов** со значениями и примерами. **Интернет для работы не требуется.**

При каждом запуске отсутствующие слова автоматически добавляются в локальную базу со статусом «не изучено», поэтому при появлении нового уровня существующий прогресс не сбрасывается.
